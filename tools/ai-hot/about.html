内容从哪里来

软云 AI 热点基于 AIHOT 开源框架适配，保留示范信源、行业分类、评分提示词与入选门槛。界面使用 SoftCloud 品牌，服务运行在 Cloudflare。公开信源为 RSS / Atom，覆盖官方博客、研究机构、媒体和作者。

内容依次进行相关性预筛、两次独立评分与中文整理。官方一手信源的平均入选门槛为 60，准官方为 65，媒体与个人为 76。评分相加后与两倍门槛比较。摘要由 AI 辅助生成，每条都提供原文链接。

热点与早报

相关报道会尝试归为同一事件；有较高置信度才合并。48 小时内，每个独立来源只贡献一次热度，24 小时减半。发现时已经发布超过 48 小时的旧内容归档，不进入当前精选或热点。

每天北京时间 08:00 起，已有精选会整理成早报；没有合适内容时不生成空早报。免费额度用完或信源无法访问时，收录与整理会暂停或延迟，已有内容仍可阅读。

免费适配范围

此版本提供 18 个 RSS / Atom 示范信源、预筛、双评分、中文摘要、热点、日报、搜索、当前浏览器收藏、公开读取 API 与精选 RSS。数据库和后台任务已从原版的 PostgreSQL / pg-boss 改为 Cloudflare D1 / Queues / Cron。

原项目的付费 X 与公众号采集、模型榜、Codex 监控、全文翻译、向量召回、独立第二模型合并复核、周报月报和 MCP 暂未适配。免费模型更换后，原评分门槛尚未重新标注校准；这会影响精选质量，不能把原项目的评测结果直接视作本版本表现。

来源与浏览器记录

原文及其版权归相应发布者，本站提供中文摘要与原文入口，不展示全文。阅读不需要账号，也不因访客打开页面触发模型调用。

收藏和主题选择保存在当前浏览器，清除网站数据后会丢失。后台储存公开信源资料、处理结果与运行记录；网络请求由 Cloudflare 托管处理，本站未新增用户画像或跨站广告追踪。
